# InsightX – Smart Automated EDA

📊 InsightX is a Streamlit app that performs smart, automated exploratory data analysis with filters, visualizations, profiling, and reports.

## 🚀 Features
- Upload CSV file and auto-clean data
- Apply filters (numeric and categorical)
- Generate insights (correlations, nulls, outliers)
- View plots (scatter, box, heatmap, pie, etc.)
- One-click data profiling (via ydata_profiling)
- Download summary reports

## 🛠 Built With
- Python
- Streamlit
- Pandas, NumPy
- Plotly
- ydata_profiling

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
